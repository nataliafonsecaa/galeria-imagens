Galeria de Imagens
Este é um projeto pessoal desenvolvido com o objetivo de estudo e prática dos conceitos fundamentais de desenvolvimento web. A galeria de imagens foi criada para explorar e aprimorar habilidades em HTML, CSS e JavaScript, com foco na criação de layouts dinâmicos, responsivos e interativos. A galeria apresenta colagens digitais e manuais criadas por mim, combinando aprendizado técnico e expressão artística.

 Estrutura do Projeto
- index.html: Página principal da galeria.
- digital.html: Página dedicada às colagens digitais.
- style.css: Estilos aplicados às páginas.
- script.js: Scripts JavaScript para interatividade.


🚀 Conceitos de JavaScript Abordados

1. DOM (Document Object Model)
Uso de document.querySelector() para selecionar elementos HTML e manipular o conteúdo da página dinamicamente.

2. Manipulação de Classes
Alteração de estilos e estados visuais por meio de classList.toggle()

3. Eventos
Utilização do addEventListener() para responder a interações do usuário (ex: clique no botão do menu)

4. Responsividade com JavaScript
A navegação da galeria se adapta a diferentes tamanhos de tela com a ajuda de JavaScript, tornando a interface mais amigável em dispositivos móveis.

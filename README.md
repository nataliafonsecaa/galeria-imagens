Galeria de Imagens 📸

Este é um projeto pessoal desenvolvido com o objetivo de estudo e prática dos conceitos fundamentais de desenvolvimento web.
A galeria de imagens foi criada para explorar e aprimorar habilidades em HTML, CSS e JavaScript, com foco na criação de layouts dinâmicos, responsivos e interativos.
A galeria apresenta colagens digitais e manuais criadas por mim, combinando aprendizado técnico e expressão artística.

Objetivos do Projeto 🎯

Praticar HTML e CSS: Criar uma estrutura semântica e estilizada para exibir as colagens de forma organizada.
Explorar JavaScript: Adicionar interatividade, como efeitos de hover, exibição em tela cheia (lightbox) e navegação entre imagens.
Desenvolver responsividade: Garantir que a galeria se adapte a diferentes tamanhos de tela, proporcionando uma boa experiência em dispositivos móveis e desktops.
